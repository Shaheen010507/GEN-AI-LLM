
# CS4V48 – GenAI and LLM Laboratory

## B.E. Computer Science and Engineering

This repository contains the laboratory experiments completed for the course **CS4V48 – Generative AI and Large Language Models Laboratory**. The experiments focus on foundation models, prompt engineering, retrieval-augmented generation, multimodal AI, diffusion models, fine-tuning, deployment, and evaluation of Generative AI applications using Python and modern AI frameworks.

# Experiment Summary

### Experiment 1 – Text Generation

Implemented GPT-style text generation using pre-trained foundation models and explored decoding strategies such as sampling, top-k, and top-p generation.

### Experiment 2 – Prompt Engineering

Applied zero-shot, few-shot, and chain-of-thought prompting techniques for reasoning and content generation tasks.

### Experiment 3 – Conversational AI Chatbot

Developed a simple transformer-based conversational chatbot for interactive text generation.

### Experiment 4 – Summarization and Question Answering

Built a text summarization and question-answering system using transformer-based language models.

### Experiment 5 – Sentiment Analysis and Classification

Performed sentiment analysis and document classification using foundation-model-based approaches.

### Experiment 6 – Retrieval-Augmented Generation

Implemented a RAG workflow including document retrieval, context construction, and grounded answer generation.

### Experiment 7 – Code Generation and Debugging

Created an AI-assisted code generation and debugging application for Python programming tasks.

### Experiment 8 – Image Generation

Implemented a text-to-image generation workflow inspired by diffusion-model pipelines.

### Experiment 9 – Multimodal AI

Integrated text and image processing for image captioning and visual question answering tasks.

### Experiment 10 – Fine-Tuning

Demonstrated the workflow of adapting a pre-trained language model to a domain-specific text-classification task.

### Experiment 11 – Multimedia Content Generation

Generated text, image, and audio outputs from a single user topic using a multimodal content-generation pipeline.

### Experiment 12 – Deployment and Evaluation

Deployed a Generative AI application using Gradio and evaluated generated outputs using ROUGE-style metrics.
